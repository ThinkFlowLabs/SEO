# MB Clean Solutions - Kit de resenas (agosto 2026)

Kit para conseguir resenas de Google con contenido util para el posicionamiento local:
criterio de que debe decir una resena, 7 plantillas visuales en 1080x1350 y los mensajes
listos para pedirla a cada cliente el dia que se cierra el trabajo.

Contexto: el perfil tiene 0 resenas frente a 43 a 116 de los lideres, y el ticket de entrada
al pack local de Aventura son 11. Un competidor con 22 resenas supera a uno con 105 porque
sus resenas nombran el servicio. De ahi que el kit insista en el TEXTO, no en la cantidad.

Las tarjetas 01, 02 y 03 llevan sello "Ejemplo" porque todavia no hay resenas reales.
